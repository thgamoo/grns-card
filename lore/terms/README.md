# Terminology

`lore/terms/` is the editorial dictionary for translating generic card-game
language into GRNS language.

This is not the short player-facing keyword table. Player-facing rule terms live
in `docs/keywords.md`. This directory keeps the thinking behind those choices:
candidate terms, rejected terms, tone notes, and one-to-many mappings from common
TCG/LCG vocabulary into GRNS-specific language.

## Directory Role

- Track the currently adopted term.
- Preserve alternate candidates that were considered.
- Explain why a term fits or does not fit the setting.
- Keep card text, UI labels, tutorials, lore notes, and image briefs from
  drifting into different names for the same system object.
