# Card Illustration Rule

For a card illustration, read the card note first, then its scene context. The
card supplies the subject and game gesture. The scene supplies place, time,
event pressure, and visual language.

## Required Read Order

1. `lore/cards/**/<serial>.md`
2. linked `scene_context`
3. linked region, site, period, event
4. linked faction, society, motif, material, palette
5. `lore/visual/style-core.md`
6. linked `lore/visual/style-profiles/*.md`
7. `lore/visual/anti-realism.md`
