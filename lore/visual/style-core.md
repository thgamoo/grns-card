# Style Core

This is the minimum shared visual grammar for GRNS images.

Style profiles, scenes, factions, and cards can bend the mood. They should not
break these core principles.

## Core Direction

- Treat every scene as a recorded omen, rite, rumor, or battlefield memory.
- Let objects carry meaning: gates, bells, masks, flags, bowls, fur, ash, rope,
  iron, rice, and old cloth should do narrative work.
- Prefer graphic silhouettes, ritual staging, and strong material surfaces over
  anatomical realism.
- Keep the old-world feeling, but avoid direct museum reconstruction.

## Useful Visual Anchors

- ink-dark contours
- old paper warmth
- uneven ritual objects
- compressed stage-like depth
- symbolic weather
- visible handmade texture

## Avoid

- photorealistic lens language
- modern fantasy armor defaults
- smooth game-cinematic lighting
- generic medieval props
- clean digital concept-art gradients
