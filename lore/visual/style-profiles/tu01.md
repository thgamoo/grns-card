# TU01 Tutorial

## One Line

Tutorial images should be simpler and more legible than main-set cards while
still belonging to the same ritual archive.

## Direction

- Emphasize clear silhouettes and readable action.
- Let the first-gate setting do the worldbuilding work.
- Use restrained drama; tutorial cards should not look like final-boss art.

## Avoid

- overcomplicated battlefield scenes
- excessive horror
- sterile teaching-diagram composition
