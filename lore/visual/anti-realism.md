# Anti Realism

Use this guardrail whenever an image prompt drifts toward a realistic fantasy
painting. Style profiles can add local avoid-rules, but this global guardrail
stays active.

## Push Away From

- realistic skin pores, film lighting, lens blur, and depth-of-field language
- exact historical costume reconstruction
- over-rendered muscles, fur, feathers, metal, or facial expressions
- modern battlefield smoke and cinematic dust
- polished heroic portrait composition

## Pull Toward

- stylized mythic anatomy
- ink-wash edges and blocky silhouette logic
- theatrical staging
- symbolic scale
- old-card illustration texture
- motifs that repeat like a visual grammar

## Prompt Reminder

The image should read as an artifact from the GRNS world, not as a photograph of
something that could have existed.
