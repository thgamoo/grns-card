# Reference Sources

External historical references live here. These notes are not in-world GRNS
events; they are source material for extracting tactical patterns, campaign
ideas, visual motifs, and possible system mechanics.

Each large war or era has its own directory. Inside each directory, prefer one
Markdown note per battle, siege, campaign, offensive, or operation.

## Topic Directories

- `peloponnesian-war/`
- `second-punic-war/`
- `gallic-wars/`
- `crusades/`
- `mongol-conquests/`
- `hundred-years-war/`
- `thirty-years-war/`
- `napoleonic-wars/`
- `world-war-i/`
- `world-war-ii/`

## Tactical Note Flow

Use each generated note's `## Tactical Reading Notes` section for editorial
extraction. Keep source facts and GRNS interpretation separate.

Recommended sections:

- `English Source Terms`
- `English Source Story`
- `Korean Tactical Notes`
- `GRNS Story Adaptation`
- `Possible GRNS Mechanics`
- `Visual Motifs`
- `Reliability Notes`

`English Source Story` should be a time-ordered unordered list. Keep it factual:
write clear subjects and actions, avoid speculative wording, and move tactical
interpretation into the Korean or GRNS sections.

Later extraction can summarize approved notes into:

- reusable system mechanics
- campaign encounter structures
- faction-specific tactical patterns
- visual prompt motifs
- card keyword candidates
