# 시작 덱의 첫성문

## One Line

규칙을 배우는 첫 전쟁터이자, 짐승 문지기와 작은 주술사들이 성문 앞에서 전쟁의 몸짓을 흉내 내는 장면권.

## Image Use

`ob01` 시작 덱과 첫성문 관련 일러스트의 기본 배경으로 사용한다.

## Must Appear Often

- 문지기 자리와 성문
- 범, 곰, 이리, 여우, 고양이, 새 무리의 의인화된 전쟁 놀이
- 수신, 신모, 검은 새 머리 선구자 같은 보호자/관찰자 기척
- 귀엽고 우스운 말투 아래 깔린 괴력난신의 위험

## Visual Language

동물은 너무 사실적인 야생동물처럼 보이면 안 된다. 장난스럽지만 제의적이고, 작은 카드 효과 하나에도 성문과 매장지의 세계관 규칙이 배어 있어야 한다.

## Avoid

- 아동용 동물 그림책 톤
- 실사 동물 사진 같은 털 묘사
- 현대 펫/동물원 이미지
- 너무 밝고 깨끗한 튜토리얼 UI 이미지
