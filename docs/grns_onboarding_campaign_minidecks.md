# GRNS 튜토리얼 스테이지 미니덱 기획

이 문서는 홈페이지의 **튜토리얼** 탭에서 제공할 8개 스테이지를 정의한다. 정규 시작 덱을 바로 쓰기 전에, 짧은 고정 덱 퍼즐로 게임 준비, 턴 진행, 보급, 전투, 매복, 이동, 장악, 퇴각, 퇴출, 시작 덱 운용을 순서대로 익히게 한다.

## 공통 전제

- 플레이어는 **초보 영령**이다.
- 초보 영령은 스테이지마다 힘이 1씩 오른다.

| 스테이지 | 초보 영령 |
| ---: | --- |
| 1 | 1/1 |
| 2 | 2/2 |
| 3 | 3/3 |
| 4 | 4/4 |
| 5 | 5/5 |
| 6 | 6/6 |
| 7 | 7/7 |
| 8 | 8/8 |

- 성주 텍스트의 `내`는 그 성주를 조종하는 쪽 기준이다. 아래 상대 성주의 `내`는 상대 플레이어를 의미한다.
- 각 스테이지는 고정 덱 순서로 진행한다. 특별히 적지 않은 한, 덱은 위에서부터 순서대로 확인한다.
- 튜토리얼 전용 상대 성주는 정식 대전용 카드가 아니라 규칙 교보재다. 패배 조건을 카드 텍스트에 직접 적어도 된다.
- 미니덱은 정답 카드가 첫 3~5장 안에 보이도록 구성한다. 초보자는 덱 탐색보다 “무슨 키워드를 언제 쓰는지”에 집중해야 한다.
- 상대 덱에 **징집소 지키는 이리**를 1장만 넣는 스테이지는 상대의 징집과 행동을 최소화하기 위한 스크립트 장치다.

## 전체 흐름

| 단계 | 보스 | 핵심 학습 | 주요 체험 |
| ---: | --- | --- | --- |
| 1 | 하룻 이리 | 게임 준비, 멀리건, 첫 징집 | 시작 절차만 보고 승리 |

| 4 | 호가호위 여우 | 출정, 희생, 단말마 | 상대 징집소를 비워 승리 |

## 구현 메모

1. 홈페이지에서는 이 콘텐츠를 **튜토리얼**로 노출한다. 문서명은 과거 호환을 위해 그대로 둘 수 있지만, 화면 문구와 설명은 “온보딩 캠페인”이 아니라 “튜토리얼”을 사용한다.
2. 초보 영령의 힘 증가는 스테이지 선택 UI에서도 보여준다. 예: `초보 영령 4/4`.
3. 1~4스테이지는 현재 홈페이지 구현 우선 범위다. 5~8스테이지는 같은 엔진 위에 확장하되, 상대 초기 전장/문지기/덱 스크립트가 필요하다.
4. 상대 성주는 카드 DB에 넣는 정식 카드가 아니라 튜토리얼 전용 보스 데이터로 둔다.
5. 문지기 고양이와 문지기 여우는 튜토리얼 카드풀 `tu01`에 포함된 카드 DB 카드로 사용한다.
