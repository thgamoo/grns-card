# 괴력난신 폰트 설계안

작성일: 2026-05-31

## 결정 요약

괴력난신 사이트의 전용 폰트는 2종으로 나눈다.

1. **GRNS Logo Ink**
   - 기준 시안: C안
   - 용도: `괴력난신` 로고, 메인 히어로, 대표 키비주얼
   - 성격: 수묵 괴이형 + 카드 프레임/부적 감각
   - 주의: 참고 이미지의 주변 장식과 보라색 무늬는 제거한다. 글자 자체만 남긴다.

2. **GRNS Display Ink**
   - 기준 시안: A안
   - 용도: 섹션 제목, 카드명, 팩션명, 짧은 UI 표제
   - 성격: 읽힘 좋은 수묵 표제형
   - 주의: 로고만큼 장식적이면 안 된다. 작은 크기에서도 읽혀야 한다.

B안은 과하고 실제 사용처가 낮으므로 드랍한다.

## 1. 폰트 역할

### GRNS Logo Ink

이 폰트는 완성형 텍스트 폰트라기보다 브랜드 로고타입에 가깝다. 첫 목표는 `괴력난신` 네 글자를 완성도 있게 만드는 것이다.

사용 위치:

- 메인 첫 화면의 대형 `괴력난신`
- 오프라인 카드/규칙서 표지
- SNS 배너, 포스터, 캠페인 이미지
- 카드 뒷면 또는 박스 아트의 브랜드 마크

사용하지 않을 위치:

- 긴 문장
- 메뉴 버튼
- 카드 효과 텍스트
- 검색, 필터, 버전 선택 UI

### GRNS Display Ink

이 폰트는 사이트와 카드 UI에 반복적으로 쓰는 표제 서체다. `GRNS Logo Ink`보다 덜 장식적이고, 글자 골격이 더 안정적이어야 한다.

사용 위치:

- `드러나는 이면`
- `카드 DB`, `룰 보기`, `튜토리얼`, `시작 덱`
- 카드 이름
- 팩션명: `예맥`, `사로국`, `가락국`, `십제`, `중립`
- 세계관/룰 문서의 장 제목

사용하지 않을 위치:

- 룰 본문
- 카드 효과 본문
- 긴 세계관 문단

## 2. 시각 방향

공통 방향은 “고대 기록물에 찍힌 먹 글자가 괴이의 기운에 번지고 갈라진 듯한 한국형 판타지 TCG 표제 서체”다.

키워드:

- 고서체
- 수묵
- 괴이
- 불길한 역사 기록
- 부적
- 카드 프레임
- 검은 먹선
- 찢긴 획끝

피해야 할 방향:

- 서양 고딕풍
- 피가 흐르는 호러 로고
- 네온/사이버펑크
- 중국풍/일본풍으로 강하게 보이는 장식
- 읽히지 않는 흘림 캘리그래피
- 모든 획에 과한 번짐

## 3. 조형 규칙

### 공통 골격

- 기본 골격은 명조/해서 계열에서 출발한다.
- 세로획은 굵고 검게 둔다.
- 가로획은 상대적으로 얇고 긴장감 있게 둔다.
- 글자 내부 공간은 넉넉하게 남겨 작은 크기에서도 뭉개지지 않게 한다.
- 획 끝은 둥글게 닫지 않고, 마른 붓이나 찢긴 먹처럼 마감한다.

### GRNS Logo Ink 규칙

- `괴력난신` 전용으로 글자마다 개성을 강하게 줄 수 있다.
- 카드 프레임의 각진 장식 언어를 일부 반영한다.
- 보라색 기운, 배경 장식, 테두리 문양은 폰트 자체에는 넣지 않는다.
- 먹 번짐은 글자 바깥 실루엣에만 제한적으로 둔다.
- 아주 얇은 외곽 먹그림자는 허용한다. 단, 글자의 일부처럼 보이게 하고 별도 장식처럼 보이지 않게 한다.
- 로고로 썼을 때 네 글자의 덩어리감이 우선이다.
- 배열은 우선 가로 1줄만 제작한다. 세로 배열은 추후 필요할 때 별도 논의한다.

### GRNS Display Ink 규칙

- 같은 구조를 다른 글자에도 확장할 수 있어야 한다.
- 글자당 강한 먹 번짐은 1-2곳으로 제한한다.
- 카드명 32px 전후에서도 읽혀야 한다.
- 획 대비는 유지하되, 로고보다 균일한 리듬을 가진다.
- UI 안에서 `Gowun Batang` 대체재로 작동해야 한다.

## 5. 글자별 설계 메모

### 괴

- 네 글자 중 가장 괴이한 인상을 담당한다.
- 오른쪽 복합 구조는 너무 어둡게 채우지 않는다.
- 마지막 획의 바깥쪽에 먹 번짐을 줄 수 있다.

### 력

- 가장 짧고 힘 있는 글자다.
- 전체 덩어리는 압축감 있게 잡는다.
- 아래로 빠지는 획 끝을 칼자국처럼 날카롭게 처리한다.

### 난

- 불안정함을 담당한다.
- 받침은 너무 복잡하지 않게 정리한다.
- 좌우 균형을 살짝 흔들어도 되지만, 읽힘은 유지한다.

### 신

- 신성함과 섬뜩함을 같이 담당한다.
- 왼쪽 구조는 부적의 각진 획처럼 처리한다.
- 마지막 세로 흐름은 길고 날카롭게 남겨 로고의 여운을 만든다.

## 6. Figma 제작 순서

1. 기존 `Gowun Batang Bold` 또는 유사한 명조 계열로 기준 글자를 크게 배치한다.
2. 텍스트를 outline/vector로 변환한다.
3. 글자 골격을 먼저 정리한다. 이 단계에서는 번짐을 넣지 않는다.
4. 세로획과 가로획 대비를 조정한다.
5. 각 글자당 1-3곳만 획끝을 찢거나 먹 번짐 조각을 붙인다.
6. `GRNS Logo Ink`는 C안 참고 이미지처럼 덩어리감과 의식적 분위기를 강화한다.
7. `GRNS Display Ink`는 A안처럼 읽힘과 반복 사용성을 우선한다.
8. 검정 단색 버전을 먼저 만든다.
9. 종이 배경 위에서 확인한다.
10. 실제 사이트 히어로와 카드명 위치에 목업으로 얹어본다.

## 7. 테스트 기준

### 크기 테스트

- 140px 이상: 로고/히어로
- 64px: 섹션 제목
- 32px: 카드명
- 20px 이하: 사용하지 않는 것을 기본으로 한다.

### 화면 테스트

- 메인 첫 화면
- 카드 DB 카드명
- 룰/세계관 제목
- 모바일 375px
- 데스크톱 1440px
- 밝은 종이 배경
- 수묵 히어로 이미지 위

### 판정 기준

- `괴력난신`이 1초 안에 읽히는가
- 카드 프레임의 검은 장식선과 싸우지 않는가
- 모바일에서 받침이 뭉개지지 않는가
- `Gowun Batang`보다 괴력난신만의 얼굴이 생기는가
- 장식이 글자보다 먼저 보이지 않는가

## 9. 남은 결정 질문

### GRNS Logo Ink

1. 얇은 외곽 먹그림자는 허용한다.
2. `괴력난신` 네 글자의 배열은 가로 1줄만 제작한다. 세로 배열은 추후 논의한다.

### GRNS Display Ink

1. 카드명에 실제 적용할지 여부를 정해야 한다. 적용한다면 32px 기준 읽힘을 최우선으로 둔다.
2. 영문/숫자는 한글과 같은 먹질감으로 만들지, UI 숫자답게 더 단정하게 만들지 정해야 한다.
