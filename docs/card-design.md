# 괴력난신 카드/클래스 설계

## 세계관 축

**괴력난신**는 원삼국~삼국시대의 어두운 신화적 상상력을 바탕으로 한 카드게임이다. 서양식 마법과 직업 체계 대신, 용력, 괴이, 반란, 귀신이라는 네 가지 초자연적 힘을 국가/세력별 클래스 정체성으로 삼는다.

## 핵심 클래스

| 국가/세력 | 클래스 | 담당 테마 | 덱 정체성 |
|---|---|---|---|
| 예맥 | 개마무사 | 용력 | 높은 공격성, 돌파, 연속 공격, 전장 압박 |
| 사로국 | 이매망량 | 괴이 | 패트랩, 반응형 카운터, 뒤집힘 효과 |
| 가락 | 야철장 | 반란 | 책사 운용, 막사 조작, 고코스트 유닛 생산 |
| 십제 | 주혼귀사 | 귀신 | 패장 연계, 파괴될 때 효과, 되살림과 저주 |

## 카드 레이아웃

카드는 다음 구조를 기본으로 한다.

실물 출력 기준 카드 크기는 **63mm x 88mm**로 고정한다. TCG/포커 계열 표준 카드 규격에 맞추며, 웹 미리보기와 프린트 뷰 모두 같은 `mm` 단위를 사용한다.

1. 상단
   - 왼쪽 위 비용: 원형 숫자
   - 카드명
   - 오른쪽 위 힘
   - 세력/팩 정체성을 드러내는 프레임과 문양
2. 중단
   - 카드 일러스트: `illustration` 필드가 있으면 해당 이미지를 사용하고, 없으면 카드별 한자 `sigil`로 구분
3. 하단
   - 효과 텍스트
   - 진언 키워드: `[출정]`, `[매복]`, `[단말마]` 등
   - 카드 타입: 일반/매복/지원/성주 등
4. 외부 정보
   - 종족
   - 카드 타입
   - 힘

플레이버 텍스트는 `lore`에 보관한다. 카드 표면에 넣을지 여부는 카드별 텍스트 밀도와 출력 가독성을 보고 결정한다.

카드마다 `serial`, `sigil`, `illustration` 필드를 가진다. 시리얼 넘버는 카드 하단에 작은 글씨로 표시한다.

## 클래스별 시각 구분

| 클래스 | 데이터 ID | 문양 |
|---|---|---|
| 예맥 · 개마무사 | `ym` | △ |
| 사로국 · 이매망량 | `sr` | ★ |
| 가락 · 야철장 | `gr` | ■ |
| 십제 · 주혼귀사 | `sj` | ● |
| 중립/튜토리얼 | `ne` | ◇ |

## 팩 구성

2026-05-31 기준 데이터는 `base` 대신 팩 ID를 명시적으로 나눈다.

| 팩 | 역할 |
|---|---|
| `tu01` | 옛이야기. 초보자용 이야기/튜토리얼 카드풀 |
| `ob01` | 온보딩. 튜토리얼 엔진에서만 쓰는 온보딩 카드풀 |
| `st01` | 예맥 기본 카드풀 |
| `st02` | 가락 기본 카드풀 |
| `st03` | 사로국 기본 카드풀 |
| `st04` | 십제 기본 카드풀 |
| `ex01` | 첫 번째 확장팩, 드러나는 이면 |

덱 리스트 JSON은 데이터 검증과 튜토리얼/플레이테스트용으로 유지한다. 공개 사이트의 주 탐색 구조는 스트럭쳐 덱 탭이 아니라 카드 DB, 룰, 설명, 튜토리얼이다.

## 클래스별 디자인 방향

### 예맥 - 개마무사

예맥은 개마무사의 돌격성과 산성 전투의 압박감을 앞세우는 공격적 클래스다. 용력은 몸 안에 깃든 괴력, 용혈, 전장의 분노를 의미한다.

- 핵심 키워드: 용력, 돌파, 분노, 선공, 자해 보상
- 추천 카드 타입: 일반 중심
- 주요 플레이 감각: 빠르게 밀어붙이고, 돌파로 성주를 압박

### 사로국 - 이매망량

사로국은 도깨비와 이매망량 컨셉의 카운터 클래스다. 괴이는 상대의 행동에 반응해 나타나는 숨은 위협이다.

- 핵심 키워드: 매복, 뒤집힘, 응답, 패에서 발동, 행동 취소
- 추천 카드 타입: 매복 중심
- 주요 플레이 감각: 상대 턴에 개입하고, 공격 선언과 카드 발동을 비틀며 템포 회수

### 가락 - 야철장

가락은 철기문화와 반란의 클래스다. 야철장은 막사를 운용해 고코스트 유닛과 무기를 생산한다.

- 핵심 키워드: 책사, 주조, 막사, 고코스트, 반란
- 추천 카드 타입: 책사와 대형 일반
- 주요 플레이 감각: 초반 자원을 태워 중후반 강력한 철혈 유닛을 생산

### 십제 - 주혼귀사

십제는 귀신과 죽은 자의 힘을 다루는 클래스다. 귀신 카드는 패장과 파괴 타이밍에서 효과가 강해진다.

- 핵심 키워드: 패장, 파괴될 때, 되살림, 원혼, 저주
- 추천 카드 타입: 일반과 책사 혼합
- 주요 플레이 감각: 죽어도 손해가 적고, 패장에 쌓인 카드가 후반 자원이 됨
